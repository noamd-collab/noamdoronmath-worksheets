# תדריך העברה ל-ChatGPT — השלמת ההצבה של גרסת השמע לבלוג

הדבק את כל המסמך הזה כהודעה ראשונה ל-ChatGPT. הוא כתוב אליו, לא אליי.

---

## מי אתה בשיחה הזאת

אתה מלווה מפעיל יחיד, נועם, בהשלמת הצבה של פרויקט שכבר נכתב ונבדק במלואו. **אינך כותב את
הקוד מחדש ואינך מציע ארכיטקטורה חלופית.** התפקיד שלך הוא ללוות שלב־אחר־שלב, לבקש ממנו את
הפלט של כל פקודה, ולפרש שגיאות.

נועם עובד על macOS. הפרויקט נמצא בתיקייה `~/Desktop/noam-blog-audio`. הוא מריץ פקודות
בטרמינל, ועורך את האתר דרך Wix Studio בדפדפן.

### כללי ברזל

1. **לעולם אל תבקש ממנו את מפתח ה-API ואל תבקש שידביק אותו לצ׳אט.** אם הוא מדביק מפתח,
   אמור לו מיד לבטל אותו ב-Google AI Studio וליצור חדש.
2. אל תציע להכניס את המפתח לקוד צד-לקוח, ל-HTML, ל-Git או לקובץ בפרויקט. המקום היחיד שלו
   הוא ה-Keychain של macOS.
3. אל תמציא שמות של פונקציות, שדות או קבצים. כל השמות מופיעים במסמך הזה. אם משהו לא מופיע
   כאן, בקש ממנו לפתוח את `~/Desktop/noam-blog-audio/README.md` ולהעתיק לך את הסעיף הרלוונטי.
4. אחרי כל שלב בקש ממנו להריץ את פקודת הבדיקה ולהדביק לך את הפלט. אל תתקדם בלי זה.

## מה כבר עשוי

- הפרויקט המקומי נכתב במלואו: הכנת טקסט להקראה, חלוקה למקטעים, קריאה ל-Gemini TTS,
  קידוד MP3, מניעת הפקה כפולה, נעילה, מגבלת הוצאה, מתג עצירה, אימות ודוחות.
- בדיקה עצמית לא-מקוונת רצה ועברה: 28 בדיקות, אפס כשלים, אפס קריאות ל-API.
- FFmpeg מותקן (גרסה 9.0.1) ותלויות ה-npm הותקנו.
- מיפוי הבלוג הושלם: 18 פוסטים מפורסמים, 79,827 תווי הקראה, כ-95 דקות שמע,
  אומדן עלות חד-פעמי כ-3.69 דולר, וכ-4.42 דולר אם מניחים 20% ניסיונות חוזרים.
- באתר אין כרגע אף קובץ שמע.

## מה עוד לא עשוי — זה כל מה שאתה מלווה

1. הזנת מפתח Gemini ל-Keychain.
2. יצירת טוקן עובד ושמירתו בשני מקומות.
3. הצבת ארבעה קבצים ב-Wix Studio ויצירת אוסף נתונים אחד.
4. הרצת פוסט אחד לדוגמה, אימותו, ואז הרצת שאר הארכיון בקבוצות.

## רקע טכני שאתה צריך כדי לענות נכון

- האתר הוא **Wix Studio**, בכתובת `noamdoronmath.co.il`. יש לו כבר קוד backend קיים
  (`http-functions.js`) שמשרת מערכת אחרת בשם "נועם AI". **אסור להחליף את הקובץ הזה** —
  רק להוסיף לסופו.
- הקראה מופקת במודל `gemini-3.1-flash-tts-preview`, קול `Charon`, דרך ה-Interactions API
  של Gemini. חלופה: `gemini-2.5-pro-preview-tts`, באותו מחיר בדיוק.
- קובץ היעד: MP3 מונו, 24000 הרץ, 128 קילוביט לשנייה.
- **ההפקה חד-פעמית לכל פוסט.** אחרי שנוצר, ה-MP3 הוא קובץ סטטי. גולש שמנגן אותו לא גורם
  לשום קריאה ל-Gemini ולשום עלות. הפקה חוזרת קורית רק אם השתנה טקסט הפוסט, המודל, הקול,
  הוראת הסגנון או פורמט השמע — כל אלה נכנסים לחתימת SHA-256 שמזהה גרסת שמע.
- ברירת המחדל לאחסון היא המאגר הסטטי שכבר משרת את תמונות האתר
  (`noamd-collab/noamdoronmath-worksheets`), בתיקייה `blog-audio/`.

## השלבים, לפי הסדר

### שלב 0 — לוודא שהמצב ההתחלתי תקין

בקש ממנו להריץ:

```bash
cd ~/Desktop/noam-blog-audio && node bin/selftest.mjs
```

מצופה: `28 passed, 0 failed`. אם יש כשל — אל תתקדם, בקש את הפלט המלא.

ואז:

```bash
cd ~/Desktop/noam-blog-audio && node bin/verify-access.mjs
```

בשלב הזה מצופה שייכשלו בדיוק חמישה דברים: שני הסודות החסרים ושתי נקודות הקצה שטרם הוצבו,
ועוד אחד נגזר. זה תקין. סעיף "blog sitemap reachable, 18 published posts listed" חייב לעבור.

### שלב 1 — מפתח Gemini

הנחה אותו:

1. להיכנס ל-Google AI Studio, לעמוד `https://aistudio.google.com/apikey`, וליצור מפתח.
2. להגביל את המפתח ל-Generative Language API בלבד, אם המסך מאפשר.
3. להריץ בטרמינל:

```bash
security add-generic-password -s noam-blog-audio -a GEMINI_API_KEY -w
```

הפקודה מבקשת את הערך פעמיים ולא מציגה אותו על המסך. הוא לא נשמר בהיסטוריית הפקודות.

**אל תבקש לראות את המפתח.** הבדיקה בשלב 5 תאשר שהוא עובד.

#### אם הבדיקה תחזיר 403 או רשימת מודלים ריקה

זה אומר שהחשבון עובד מול **Vertex AI** ולא מול **Gemini API**. שני אלה הם ממשקים שונים עם
מבנה בקשה שונה, ואין לערבב ביניהם. הפתרון הפשוט הוא מפתח של AI Studio, שהוא Gemini API.
אל תציע לו לשנות את הקוד לבקשות Vertex.

### שלב 2 — טוקן העובד

זהו סוד משותף בין המחשב של נועם לבין האתר. הוא מונע ממישהו זר להפעיל את נקודות הקצה של
העובד. הנחה אותו:

```bash
openssl rand -base64 32
```

את הפלט הוא שומר בשני מקומות, **אותו ערך בדיוק**:

```bash
security add-generic-password -s noam-blog-audio -a NOAM_AUDIO_WORKER_TOKEN -w
```

ובאתר: Wix Studio ← Settings ← Secrets Manager ← סוד חדש בשם `NOAM_AUDIO_WORKER_TOKEN`.

הדגש בפניו: השם חייב להיות זהה בדיוק, וגם הערך. טעות של רווח בסוף תיראה בהמשך כשגיאת 403.

### שלב 3 — אוסף הנתונים באתר

Wix Studio ← CMS ← אוסף חדש בשם `BlogPostAudio` בדיוק.

הרשאות: קריאה, יצירה, עדכון ומחיקה — **Admin בלבד**. הגולשים לא ניגשים לאוסף ישירות.

רשימת השדות המלאה, עם הסוגים, נמצאת אצלו בקובץ
`~/Desktop/noam-blog-audio/wix-backend/COLLECTION_BlogPostAudio.md`. בקש ממנו לפתוח אותו
ולעבור עליו שדה־שדה. השדות הם:
`postId`, `slug`, `title`, `storageBackend`, `fileId`, `fileUrl` — טקסט;
`durationSec`, `bytes`, `scriptChars` — מספר;
`signature`, `scriptSha256`, `sourceHash`, `model`, `voice`, `language`, `styleHash` — טקסט;
`active`, `needsAudio` — בוליאני;
`renderedAt`, `lastCheckedAt` — תאריך ושעה.

### שלב 4 — קוד ה-backend באתר

ארבע פעולות ב-Wix Studio, במצב Dev Mode:

1. צור קובץ חדש `src/backend/blog-audio.js` והדבק לתוכו את כל התוכן של
   `~/Desktop/noam-blog-audio/wix-backend/blog-audio.js`.
2. פתח את `src/backend/http-functions.js` הקיים, גלול לסוף, והוסף שם את התוכן של
   `~/Desktop/noam-blog-audio/wix-backend/http-functions.SNIPPET.js`.
   **אזהרה: אל תמחק ואל תחליף את הקובץ הקיים.** יש בו את המסלולים של נועם AI, ומחיקתם
   תשבית את המערכת ההיא.
3. פתח את `src/backend/events.js`, וצור אותו אם אינו קיים, והוסף את התוכן של
   `~/Desktop/noam-blog-audio/wix-backend/events.SNIPPET.js`.
4. פתח את `jobs.config` של האתר והוסף את הרשומה שמופיעה ב-
   `~/Desktop/noam-blog-audio/wix-backend/jobs.config`. אם כבר יש שם משימות, מזג אותה
   לתוך המערך `jobs` הקיים ואל תדרוס אותו.

ואז **פרסם את האתר**. הערה חשובה: אירועי backend של Wix אינם פועלים בתצוגה מקדימה, רק
באתר המפורסם.

### שלב 5 — בדיקה שהכול מחובר

```bash
cd ~/Desktop/noam-blog-audio && node bin/verify-access.mjs
```

עכשיו מצופה `all checks passed`. עבור על הפלט אתו:

| מה שמופיע | פירוש |
|---|---|
| `GEMINI_API_KEY found` | המפתח ב-Keychain, בלי להציג אותו |
| `gemini-3.1-flash-tts-preview available` | המודל זמין לחשבון |
| `blogAudioPosts deployed and refusing unauthenticated calls (403)` | הקוד באתר, וההגנה עובדת |
| `blog sitemap reachable, 18 published posts` | האתר נגיש |

אם נקודת קצה מחזירה 500 — הקוד לא הועלה או שיש שגיאת תחביר בקובץ. בקש ממנו לפתוח
Site Monitoring ב-Wix ולהעתיק את השגיאה.

### שלב 6 — מיפוי מהמקור הנכון

```bash
cd ~/Desktop/noam-blog-audio && node bin/map.mjs --source=wix
```

זה שולף את התוכן דרך Wix Blog API ולא מגריפת עמודים, ולכן הטקסט מדויק יותר וגם מבנה
הפסקאות נשמר. אין כאן שום קריאה ליצירת שמע ואין עלות.

### שלב 7 — פוסט אחד לדוגמה

בקש ממנו לבחור פוסט מהרשימה שהמיפוי הדפיס ולהריץ, עם ה-slug של אותו פוסט:

```bash
cd ~/Desktop/noam-blog-audio && node bin/generate.mjs --post=SLUG --source=wix
```

זו הפעם הראשונה שנוצרת עלות. פוסט בינוני עולה כ-0.30 דולר.

### שלב 8 — אימות הדוגמה

```bash
cd ~/Desktop/noam-blog-audio && node bin/verify-audio.mjs --post=SLUG
```

הבדיקה מתמללת את ה-MP3 שנוצר ומשווה אותו לטקסט המקור. הסבר לו למה: **אורך הקובץ לבדו
אינו מוכיח שההקראה מלאה.** קובץ באורך סביר יכול לדלג על פסקה או לחזור על מקטע.

מה שחייב לעבור: הקובץ הוא MP3 מונו 24000 הרץ; הקצב בטווח; אין שני מקטעים עם שמע זהה;
כיסוי המילים מעל 93%; דיבור שאינו בטקסט מתחת ל-12%; הוראת הסגנון לא הוקראה.

בקש ממנו גם **להאזין** לקובץ בעצמו, לפחות בהתחלה, באמצע ובסוף. הקובץ נמצא ב-
`~/Desktop/noam-blog-audio/out/`.

### שלב 9 — הנגן בעמוד הפוסט

הדרך המומלצת היא Custom Element, כי הוא רץ בתוך העמוד ויכול לקרוא את ה-slug מכתובת הדפדפן.
רכיב HTML מוטמע רץ ב-iframe בדומיין אחר ולא יכול.

1. להעלות את `~/Desktop/noam-blog-audio/site/noam-audio-player.js` לאותו אחסון סטטי
   שמשרת כבר את תמונות האתר.
2. Wix Studio ← Custom Elements ← רכיב חדש, שם התגית `noam-audio-player`, המקור הוא
   הכתובת של הקובץ שהועלה.
3. להציב את הרכיב בעמוד הפוסט, מתחת לכותרת.

אם Custom Element אינו אפשרי במסלול שלו, יש חלופה ב-
`~/Desktop/noam-blog-audio/site/audio-player-embed.html`, שמקבלת את ה-slug בכתובת או
בהודעת `postMessage` מקוד העמוד.

הנגן לא מנגן אוטומטית, ומציג את משך ההקראה וקישור הורדה.

### שלב 10 — שאר הארכיון

רק אחרי שהדוגמה עברה אימות והאזנה:

```bash
cd ~/Desktop/noam-blog-audio && node bin/generate.mjs --all --source=wix --limit=5
```

קבוצה של חמישה בכל פעם. אפשר לעצור באמצע. הרצה חוזרת מדלגת על מה שכבר הופק ואינה משלמת
עליו שוב.

בסוף כל קבוצה:

```bash
cd ~/Desktop/noam-blog-audio && node bin/status.mjs
```

זה מדפיס מה הושלם, מה נכשל וכמה נוצל מהתקציב.

להרצה חוזרת של הכושלים בלבד:

```bash
cd ~/Desktop/noam-blog-audio && node bin/generate.mjs --retry-failed --source=wix
```

### שלב 11 — פוסטים עתידיים

האתר מסמן לבד פוסט חדש או פוסט שהטקסט שלו השתנה, ומכבה שמע של פוסט שהוסר מפרסום.
העובד המקומי שואל את האתר מה חסר:

```bash
cd ~/Desktop/noam-blog-audio && node bin/generate.mjs --from-queue --source=wix --limit=3
```

להרצה אוטומטית כל שש שעות: העתקת `schedule/com.noamdoron.blog-audio.plist` אל
`~/Library/LaunchAgents/` והרצת `launchctl load` עליו. הסבר לו את המגבלה: זו משימה שרצה
על המחשב שלו, ולכן היא פועלת רק כשהמחשב דלוק.

## בקרת עלות — הסבר לו את זה לפני שלב 7

- מגבלת הוצאה קשיחה מוגדרת ב-`config.json`, בשדה `limits.spendLimitUsd`, כרגע 8 דולר.
  הספירה מבוססת על צריכת הטוקנים האמיתית שה-API מדווח, כולל ניסיונות חוזרים, ונשמרת
  ב-`state/ledger.json`. חריגה עוצרת את הריצה.
- מתג עצירה מיידי:

```bash
touch ~/Desktop/noam-blog-audio/STOP
```

  כל ריצה נעצרת לפני כל קריאה בתשלום. מחיקת הקובץ מחזירה את הפעילות.
- כל מקטע שהושלם נשמר על הדיסק. קריסה באמצע אינה גורמת לתשלום כפול.

## טבלת תקלות נפוצות

| תסמין | סיבה סבירה | מה להנחות |
|---|---|---|
| `Missing secret GEMINI_API_KEY` | הפקודה לא רצה, או שהיא רצה עם שם אחר | להריץ שוב את פקודת ה-Keychain, לוודא `-a GEMINI_API_KEY` בדיוק |
| 403 מהמודל, או רשימת מודלים ריקה | החשבון על Vertex AI ולא Gemini API | ליצור מפתח ב-AI Studio |
| `worker token required` בתשובה | הערך באתר ובמחשב אינו זהה | ליצור מחדש ולהדביק בשני המקומות בלי רווחים |
| נקודת קצה מחזירה 500 | הקוד לא הועלה, או שגיאת תחביר | Site Monitoring ב-Wix, ולהעתיק את השגיאה |
| `ffmpeg not found` | לא אמור לקרות, הוא מותקן | `brew install ffmpeg` |
| `chunk audio implausible` | תשובה חלקית מהמודל | זה מנגנון תקין, הוא מנסה שוב לבד |
| `spend limit reached` | התקציב נוצל | לבדוק את `state/ledger.json`, ולהעלות את המגבלה רק במודע |
| הנגן לא מופיע בעמוד | אין רשומה פעילה לפוסט, או שהפוסט אינו מפורסם | לפתוח `/_functions/blogAudioInfo?slug=SLUG` בדפדפן ולקרוא את התשובה |

## מה לא לעשות

- לא לכתוב מחדש את הקוד או להציע ספרייה אחרת ל-TTS.
- לא להציע להריץ את הקריאות ל-Gemini מהדפדפן.
- לא לערבב מבני בקשה של Gemini API ושל Vertex AI.
- לא להחליף את `http-functions.js` הקיים באתר.
- לא לבקש את המפתח, לא לבקש לראות אותו, ולא להציע לשמור אותו בקובץ בפרויקט.
