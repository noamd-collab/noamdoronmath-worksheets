# LaTeX בבלוג Wix

היישום שומר מקור אחד בפוסט: עברית רגילה לצד LaTeX מפורש. הדפדפן מעצב את
הנוסחאות באמצעות MathJax, ותהליך ההקראה ממשיך לקבל את אותו טקסט דרך Wix.
הרנדרר אינו כותב בחזרה לפוסט, אינו מפעיל TTS ואינו משנה את הנגן.

## תחביר נתמך

- נוסחה בתוך שורה: `\\(x^2+3x=0\\)`
- נוסחה בשורה נפרדת: `\\[x=\\frac{-b\\pm\\sqrt{b^2-4ac}}{2a}\\]`
- חלופה לתצוגה בשורה נפרדת: `$$x^2=49$$`
- `$...$` יחיד אינו נתמך, כדי שסכומי כסף וטקסט רגיל לא יהפכו בטעות לנוסחה.

יש לשמור לוכסן יחיד בגוף הפוסט. רק ב-JSON או בקוד JavaScript הוא נראה לעיתים
כ-`\\\\` בגלל escaping של שכבת הייצוג.

## התקנה מדורגת

1. להעלות את `site/noam-latex-renderer.js` לאחסון הסטטי הקיים.
2. להוסיף ב-Wix Custom Code, בסוף `body` ובכל העמודים, תגית `script` שטוענת את
   כתובת הקובץ. הקוד עצמו פועל רק בנתיבים שמכילים `/post/` ורק כאשר נמצאו
   מפרידי LaTeX בגוף הפוסט.
3. לפרסם תחילה פוסט בדיקה אחד עם נוסחאות `\\(...\\)` ו-`\\[...\\]`.
4. לבדוק כניסה ישירה, רענון, ניווט לפוסט אחר וחזרה, טלפון והגדלה בדפדפן.
5. רק לאחר הבדיקה להרחיב לפוסטים נוספים.

דוגמת Custom Code לאחר שהקובץ זמין ב-GitHub Pages:

```html
<script defer src="https://noamd-collab.github.io/noamdoronmath-worksheets/blog-audio/noam-latex-renderer.js"></script>
```

## התנהגות במקרה תקלה

אם MathJax או CDN אינם זמינים, מקור ה-LaTeX נשאר גלוי והמאמר אינו נחסם. אפשר
לראות מצב בזמן בדיקה דרך `window.NoamBlogLatex.state`. הסרת קוד הטעינה ורענון
העמוד מחזירים את תצוגת המקור; שינוי או שחזור תוכן הפוסט הוא פעולה נפרדת.

## הקראה

`src/text.mjs` מזהה את אותם שלושה סוגי מפרידים. ניקוי Markdown מתבצע רק מחוץ
לנוסחה, והמפצל אינו חותך באמצע נוסחה גם כשהיא סמוכה לגבול מקטע. שינוי מקור
הפוסט עדיין נחשב שינוי תוכן רגיל ועלול להכניס את הפוסט לתור ההקראה הקיים.

הרצת הבדיקות המקומיות, ללא TTS וללא רשת:

```sh
node --test test/text-latex.test.mjs
node --check site/noam-latex-renderer.js
```
