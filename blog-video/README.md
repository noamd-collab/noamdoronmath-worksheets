# blog-video: פוסט בבלוג → סרטון קצר עם הכפיל של נועם

כלי ותוכן להפקת סרטון קצר אחד לכל פוסט בבלוג, ב־HeyGen ועם הכפיל והקול של נועם, לפרסום ב־Instagram, ב־Facebook וב־YouTube Shorts.
הכלי אינו משנה את האתר, את פוסטי הבלוג או את ה־SEO. אין בו פרסום אוטומטי ואין cron.

## מבנה

| נתיב | מה זה | נכתב ע״י |
|---|---|---|
| `packages/<postId>/<variant>/script.json` | התסריט: מקטעים, טקסט מדובר, כתובית, טקסטים למסך, הפניות לבלוקים במקור, הוראות בימוי | אדם |
| `packages/<postId>/social.json` | cover, טקסטים לרשתות, פוסטים קשורים | אדם |
| `glossary.he.json` | מילים שמקבלות ניקוד, עם הגייה ונימוק | אדם |
| `briefs.json` | תקציר לכל פוסט: רעיון מרכזי, פתיחה, דוגמה, מה יושמט, בדיקת מתמטיקה | אדם |
| `packages/.../script-source.md` | תסריט ללא ניקוד + ציטוט המקור + עריכות + בימוי | `bin/build.mjs` |
| `packages/.../narration.he.niqqud.txt` | רק מה שהכפיל אומר, עם ניקוד ממוקד | `bin/build.mjs` |
| `packages/.../captions.he.txt` | אותו תוכן בלי ניקוד; נוסחאות בבידוד LTR | `bin/build.mjs` |
| `packages/.../captions.segments.json` | חלוקה לכתוביות עם זמנים **משוערים** (לא SRT סופי) | `bin/build.mjs` |
| `packages/.../storyboard.md`, `screen-text.md` | מה נאמר מול מה מוצג, ונוסחאות מדויקות לתצוגה | `bin/build.mjs` |
| `packages/<postId>/social.md` | טקסטים לפרסום עם הקישור האמיתי | `bin/build.mjs` |
| `manifest.json` | מצב כל סרטון: hashes, סטטוס תוכן, ניקוד, קול/אווטאר, הפקה, פרסום | `bin/build.mjs` + אדם |
| `inventory.json`, `inventory.csv` | מלאי כל 60 הפוסטים | `bin/build.mjs` |
| `heygen.contract.*.json` | חוזה ה־API (רק ממה שתועד רשמית) | אדם |
| `dry-run/*.json` | הבקשה שהייתה נשלחת, בלי שליחה | `bin/produce.mjs dry-run` |

## פקודות

```bash
node blog-video/bin/build.mjs                 # מחולל את כל הקבצים ומריץ את הבדיקות על כל חבילה
node --test blog-video/test/*.test.mjs        # בדיקות, כולל פגמים מוזרקים ובדיקה שהקבצים המחוללים עדכניים
node blog-video/bin/stamp.mjs <postId>/<variant> --by "<שם>"   # אחרי סקירה מול המקור
node blog-video/bin/produce.mjs plan          # מה חוסם הפקה, לכל סרטון. לא שולח דבר
node blog-video/bin/produce.mjs dry-run --id <id> --contract <file>
```

`generate`, `status`, `compare-subtitles` ו־`record-publish` מתוארים ב־[HEYGEN-ROUTE.md](HEYGEN-ROUTE.md).

## מה נבדק אוטומטית, ומה לא

נבדק בכל build ובכל הרצת בדיקות:
- כל נוסחה על המסך ובכתובית מחושבת בדיוק (שברים, בלי `eval`). טעות שמוצגת בכוונה מסומנת `expect: "false"` וחייבת להיות שגויה.
- מתמטיקה שנאמרת בעברית ("עשרים וארבע חלקי ארבע…") מתורגמת לביטוי ומושווית בערכה לביטוי שמוצג. כשהניסוח אינו ניתן לקריאה מכנית, הזוג מסומן `manual` עם נימוק.
- הטקסט המדובר: בלי ספרות, אותיות לטיניות, סימנים, קישורים, סוגריים או הוראות בימוי.
- הסרת הניקוד מהקריינות מחזירה בדיוק את הטקסט הלא מנוקד (תופס ניקוד ששינה אות, למשל כתיב מלא).
- כל מילה מנוקדת מגיעה מה־glossary; צורה אחרת של מונח מה־glossary (עם תחילית) בלי ניקוד נכשלת.
- בכתוביות אין ניקוד, וכל נוסחה בבידוד LTR (U+2066…U+2069), כדי שהסדר לא יתהפך בעברית.
- כל מקטע (חוץ מקריאה לפעולה) מפנה לבלוק קיים בפוסט; הבדל בין דיבור לכתובית מחייב סיבה מתועדת.
- משך משוער מול היעד, לפי שתי הנחות קצב (לא מדידה).
- שינוי בפוסט או בתסריט אחרי הסקירה פותח את הסקירה מחדש (`reviewedAgainst`), וההפקה נחסמת.
- מניעת כפילות: מזהה עבודה נגזר מהתסריט, מהקריינות, מהאווטאר ומהקול; אותה עבודה לא נשלחת פעמיים, ויש תקרה של 2 ניסיונות.

לא נבדק אוטומטית ואינו יכול להיבדק כאן:
- שהניקוד נכון ושהקול של נועם הוגה נכון. רק האזנה לקול הנבחר מאמתת הגייה.
- שהטענות בטקסט החופשי נאמנות לפוסט. זה נבדק בקריאה, והוא מתועד ב־`script-source.md` לצד ציטוט המקור.
- משך אמיתי, תזמון כתוביות ותצוגה בכל רשת.
