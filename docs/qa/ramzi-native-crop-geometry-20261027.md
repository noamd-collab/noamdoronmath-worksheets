The normal Brave test W07-Q1 selected G8-T12, level B, question 12ג. Its hint failed with `QUESTION_IMAGE_UNREADABLE`: the configured image was completely blank. The published PDF SHA-256 is `d1c9c0224f34a385d9ab3d91c9988caa39bda20071f871de858c40cdf6d61d4c`, matching the manifest. The replacement is measured by the existing `scripts/build-student-manifest.py` against those exact PDF bytes and its matching native export. The solver still receives the original selected-part prompt and still requires successful image analysis.

A source audit found 1,038 old crops excluded the measured selected-part pin and 149 crop sets were vertically disjoint from the measured question band. These are geometry measurements, not claims that every old request failed.

Exact text, prompts, source identity, native bindings and vision requirements remain unchanged. Root and public copies match. The viewer refreshes its manifest URL and OCR cache namespace; conversation history remains in its original namespace.
